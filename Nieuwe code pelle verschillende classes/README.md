## Overview

This folder contains the class-based implementation for the MT1463/MT1466
stability and equilibrium workflow.

The code follows the structure guidelines from:
`Tips om een Python code te organiseren`

Key design goals:
- keep one reusable generic ship calculation class;
- separate helper functions from scenario orchestration;
- support all three required ship types using subclasses;
- keep naming and documentation consistent.

## Folder layout

- `Main_pelle.py`
  - Main entry point.
  - Defines one scenario, runs all three ship types, prints summary results.
  - Writes output files:
    - `output/ship_results.json`
    - `output/ship_results_graph.png`
- `Ship_pelle.py`
  - Generic `Ship` class.
  - Handles data loading, tank interpolation, equilibrium solving, and GM.
- `Functions_pelle.py`
  - Reusable utilities:
    - `Tank` interpolation class
    - `deck(...)`
    - `plates(...)`
    - `ZCG(...)`
    - `matrix_add(...)`
- `TransportschipClass.py`
  - `TransportSchip`: deck cargo only, no crane.
- `KraanschipClass.py`
  - `KraanSchip`: crane load case, no deck cargo.
- `AlleskunnerClass.py`
  - `Alleskunner`: crane load case plus deck cargo.
- `data/`
  - Input CSV/JSON generated by Rhino/Grasshopper.
- `output/`
  - Generated JSON and graph files (created after running `Main_pelle.py`).

## Calculation workflow

1. Read hydrostatic ship data (`MainShipParticulars_...json`).
2. Build 3 tank objects from tank diagram CSV files.
3. Build dry-load matrix from:
   - deck/crane loads
   - steel plate and bulkhead weights
4. Solve equilibrium:
   - Tank 1 fill from transverse moment equilibrium
   - Tank 2 mass from vertical force equilibrium
   - Tank 2 longitudinal location from longitudinal moment equilibrium
5. Compute stability:
   - `KB` from buoyancy center
   - `KG` from mass distribution
   - `BM` from waterplane inertia with free-surface correction
   - `GM = KB - KG + BM`

## Input assumptions used in this code

- Steel density: `7850 kg/m3`
- Water density (outside + ballast): `1025 kg/m3`
- Plate+stiffener mass factor: `2.1`
- Crane mass model:
  - housing = `0.34 * SWL`
  - jib = `0.17 * SWL`
  - `SWL = TP_mass / 0.94`

These values are still configurable in `Main_pelle.py`.

## Data-path behavior

The `Ship` class first tries local `data/`.
If that folder has an unusable `MainShipParticulars` (for example buoyant volume
equals 0), it automatically falls back to:

`../Data voorbeeld ship 1 alleskunner met kraan dwarsscheeps`

This keeps the project runnable even when local export files are incomplete.

## How to run

From this folder:

```bash
python Main_pelle.py
```

Expected terminal output:
- one summary block per ship type (`TransportSchip`, `KraanSchip`, `Alleskunner`)
- saved output file locations for JSON and PNG

## Generated outputs

After a successful run:

- `output/ship_results.json`
  - Scenario constants + per-ship computed values (`tank1_percentage`,
    `tank2_percentage`, `tank2_lcg`, `KB`, `KG`, `BM`, `GM`)
- `output/ship_results_graph.png`
  - Figure with:
    - GM bar chart per ship type
    - Tank fill percentages per ship type
