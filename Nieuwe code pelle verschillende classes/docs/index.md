## Kernprincipe van deze documentatie

Elke belangrijke component is gedocumenteerd op:

- **Wat** het doet.
- **Waarom** het bestaat.
- **Welke invoer** nodig is.
- **Welke uitvoer** geproduceerd wordt.
- **Welke fouten** kunnen optreden en hoe je die oplost.
