Code Organiseren & Samenwerken

Om de code overzichtelijk te houden is een plan en verdeling van functies, classes, en Python files noodzakelijk. Een goede manier om dit te doen is door de verschillende stappen die uitgevoerd moeten worden in functies en classes op te delen in een hoofd functie, functies die voor input zorgen, functies die berekeningen maken, en functies die resultaten genereren.

Hoofdfunctie en file verdeling

In de hoofdfunctie leg je vast in welke volgorde je de andere functies gaat aanroepen (onthoud dat een functie wordt pas uitgevoerd wanneer de functie aangeroepen wordt). Verdeel de functies over verschillende python files met een logische verdeling van taken die in deze files gedaan worden. Een voorbeeld van een taak verdeling per python file zou kunnen zijn:

  • De hoofdfunctie (main.py hier start en eindigt het programma), 
  • Input (read_files.py hier zit bijvoorbeeld de functie readTankVolumes(filename) in die de tank volume csv bestanden leest, en de readMainParticulars(filename) die de JSON file leest met de hoofdafmetingen)
  • Berekening (ship_calculations.py) in deze file zitten functies die bijvoorbeeld berekend of het schip in evenwicht is, of een andere functie die berekent hoe vol de tanks moeten zijn.
  • Output (generate_output.py). In deze file zitten functies die een plot maken van hoe de GM veranderd gegeven verschillende tankvullingen, of een functie die resultaten wegschrijven in een csv.

Zorg in ieder python bestand dat de benodigde python functies geimporteerd worden. Wil je de readTankVolumes() functie in main.py gebruiken? Zet dan bovenin de main.py file: from read_files import readTankVolumes. Vervolgens kan je de readTankVolumes functie gebruiken in de main python file. 

Functie richtlijnen

Algemene richtlijnen voor functies zijn: 

  • Zorg er voor dat iedere functie een logische naam heeft,
  • Zorg er voor dat iedere functie een docstring heeft,
  • Zorg er voor dat iedere functie met een werkwoord te beschrijven is,
  • Gebruik #commentaar bij gebruik moeilijk te interpreteren regels code,
  • Voorkom gebruik van globale variabelen in functies (als je een variabele in de functie gebruikt geef hem dan mee als argument), 
  • Zorg dat een functie op één scherm past (dus niet meer dan +/-30 regels per functie anders probeer je waarschijnlijk te veel te doen in een functie)

Naamgeving conventies

Om python bestanden onverzichtelijk en leesbaar te houden raden we aan om variabelen, functies, classes, constanten, bestanden en errors logische namen te geven, niet te veel gebruik te maken van ongebruikelijke afkortingen, en de volgende naamgeving conventies te gebruiken:

Stappenplan code programmeren

  • Bedenk welke formules je nodig hebt om de benodigde output te genereren, welke input is er voor nodig, en in welke volgorde ga je deze dingen doen.
    • Maak een hoofdfunctie en logische python file verdeling (bijvoorbeeld: main.py, read_files.py, generate_output.py, ship_calculations.py).
    • Beschrijf de functies die geprogrammeerd moeten worden en definieer voor iedere functie input, output, datatypen, en een docstring.
  • Ga aan de slag met programmeren en vergeet niet de naamgeving conventies en functie richtlijnen.
  • Combineer de code door de aparte python functies een voor een aan te roepen vanuit de hoofdfunctie.
  • Test de individuele functies (geeft de functie het verwachte resultaat voor ieder redelijke input?)

Optioneel Flowchart:

Wat helpt bij het ontwerpen van de code is er een flowchart van maken. Deze flowchart beeld de hoofdfunctie uit en ieder proces in deze flowchart is een aparte functie. Gebruik in ieder geval proces blokken voor input (de functies de csv files in lezen), process blokken voor berekeningen maken (stabiliteit berekening, evenwichtsberekening), en proces blokken die output genereren (data plotten, data naar een csv wegschrijven). Geef in de flowchart in ieder geval aan:

  • De naam van de functie
  • De volgorde van de input argumenten, hun naam, en hun datatype (float, integer, list)
  • De volgorde van de return waarden, hun naam, en hun datatype (float, integer, list)
